# AxetosOS Products / NES v2.11.0

## Whole-circuit compiled laboratory motherboard experiment

This release adds an experimental `--compiled-lab` execution architecture while keeping the existing hand-fused Famicom/NROM runtime unchanged as the default fast path and keeping `--reference-runtime` as the physical correctness/performance oracle.

### Architecture

The fixed motherboard and the replaceable cartridge are separate compilation/runtime units:

1. **Compiled motherboard unit** — RP2A03, RP2C02, SRAM, CIRAM, 74-series glue logic, controllers, clocks and fixed wiring are analyzed as one assembled physical circuit.
2. **Replaceable cartridge unit** — mapper and ROM behavior remains outside the motherboard compilation boundary.

The motherboard compiler may aggressively optimize any relationship it can prove from physical chip models and topology. It does not contain NES address-map, NROM, mapper or game-specific routing rules.

### Circuit-derived compilation

- CPU read/write dispatch is generated by evaluating the actual RP2A03 address/RW pins through the installed SN74LS139A/SN74LS368A circuitry for all 65,536 source patterns.
- CPU SRAM and RP2C02 register address projections are derived from actual package-pin connections.
- PPU-side SRAM addressing is derived through the physical SN74LS373 and RP2C02 address pins, with the unresolved cartridge-controlled CIRAM contribution kept at the external boundary.
- Master-clock scheduling is derived from the installed chips' physical clock activation periods and receiver order; a 6/4 schedule may compile into the unrolled 12-edge hot kernel.
- Direct NMI and CIRAM control shortcuts are emitted only after topology validation proves the required package-pin connections.

### Replaceable mapper/ROM boundary

The first external backend is NROM because the current public ROM loader supports mapper 0. NROM PRG/CHR selection and mirroring stay inside `CompiledNromCartridgeUnit`, not the motherboard compiler. Future mapper units can be added without recompiling or teaching mapper rules to the fixed-board compiler.

### Execution modes

- default: existing fused Famicom/NROM runtime, unchanged;
- `--reference-runtime`: v2.10 physical pin/net/package execution;
- `--compiled-lab`: new whole-circuit compiled motherboard plus replaceable cartridge unit.

### Validation

Three tests are added:

- cartridge remains a physically attached external unit outside the compiled motherboard;
- whole-circuit compiled execution matches the physical reference at the same master-cycle boundary;
- APU register writes and DAC output match the physical reference.

Expected test total: **232**.
