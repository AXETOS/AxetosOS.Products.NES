AxetosOS Products / NES v1.2.0

Purpose
-------
Reduce the measured ~11 FPS Release hot-path cost while preserving the v1.1.x chip boundary.

Changes
-------
- Chip-owned input-change masks replace simulator-owned package masks.
- RP2A03/RP2A07 gate work by the input pins that actually changed.
- RP2C02/RP2C07 separate CPU-port input activity from clock/raster activity.
- PPU output driving is skipped on falling clock edges and non-dot RP2C02 divider phases.
- Simulator component dispatch uses the concrete VirtualHardwareComponent base.
- Removed the redundant net-queued bitmap and circular net queue head/tail state.
- Dirty nets are resolved as FIFO batches before the next package activation.
- Removed the zero-mask package activation check.

Validation
----------
This environment has no .NET SDK. The patch was statically checked and reconstructed/overlay-verified, but dotnet test and FPS results must be measured on the target Windows machine.
