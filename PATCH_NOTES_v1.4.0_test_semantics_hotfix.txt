AxetosOS Products / NES v1.4.0 test-semantics hotfix

Purpose
-------
Two pre-v1.4.0 regression tests still required inactive SN74LS373/HM6116
packages to execute internal component logic when their package pins changed.
That expectation contradicts v1.4.0 chip-owned pin activation gates.

The hotfix changes only those test expectations:
- physical pin delivery remains required;
- inactive/deselected package output remains unchanged;
- component evaluation count is now expected to remain zero.

No runtime/emulator source is changed.
