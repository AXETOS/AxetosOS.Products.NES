AxetosOS Products / NES v2.12.0 patch

Purpose
-------
Turn the v2.11 whole-board speed prototype into a product-agnostic hardware compiler while preserving the existing ~60 FPS hand-fused fallback.

Key points
----------
- Compiler source contains no concrete NES/Famicom/RP2A03/RP2C02/HM6116/controller/74-series/NROM role switches.
- Cross-chip shortcuts are derived from public component hardware facets + actual physical net connectivity.
- Address and data bit permutations are compiled from wiring rather than assumed logical order.
- Clock schedules are discovered from physical clock pins and activation periods.
- Replaceable cartridge/mapper/ROM remains outside the fixed-board runtime unit.
- Compiler refuses unmodelled output-capable data-bus drivers instead of silently changing hardware behavior.
- Tiny8 + generic RAM/ROM/decoder/inverter now run through the same compiler as an explicit non-NES proof.
- Default hand-fused Famicom/NROM runtime remains available and independent.
- --reference-runtime remains the full physical oracle.
- Expected test total: 233.

Performance must be validated locally before accepting v2.12 as the new compiled-lab baseline.
