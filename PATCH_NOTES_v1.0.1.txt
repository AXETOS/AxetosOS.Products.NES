AxetosOS Products / NES v1.0.1

Purpose
- Remove obsolete VirtualHardware runtime paths and contracts.
- Keep one strict indexed electrical event queue.
- Keep the physical pins, nets, buses, chip packages and master-clock path.

Application
1. Extract this ZIP over C:\Users\patri\source\repos so the AxetosOS\AxetosOS.Products.NES files are overwritten.
2. In AxetosOS.Products.NES, run:
   powershell -ExecutionPolicy Bypass -File .\Apply-v1.0.1.ps1
3. Run dotnet test.

Validation performed here
- C# lexical and delimiter validation across the source tree.
- Stale-reference searches for removed contracts, topology polling, compatibility scheduling and callback clock APIs.
- The .NET SDK is not installed in this execution environment, so dotnet test was not run here.
