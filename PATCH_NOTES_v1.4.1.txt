AxetosOS Products / NES v1.4.1

Goal: reduce the profiler-measured shared-bus/net transport cost without compromising the dumb-motherboard / smart-chip physical architecture.

Main sweep:
  - compiled O(1) electrical aggregate for traces with 3+ possible drivers
  - atomic all-driver-state update before one package change-set is presented
  - one resolution per affected physical trace per package reaction
  - faster store-only path for output-only pins
  - faster store/history path for chip-gated AnyChange inputs
  - specialized NES-hot package bus sampling/drive/release widths
  - regression tests for multi-driver strength/contention/release and shared-trace package atomicity

No motherboard-side receiver semantics, no signal queue, no scheduler, no Settle engine, and no skipped physical deliveries.
