AxetosOS Products / NES v1.3.3

Goal
----
Remove residual work from non-activating master-clock edges while preserving the queue-free physical trace model.

Runtime changes
---------------
- Add a topology-validated rising-edge-only DigitalPin fast path.
- High -> Low on the compiled master clock only records the pin's Low electrical state and returns.
- Falling edges do not enter RP2A03/RP2C02 package logic and do not touch their activation/divider counters.
- PAL equivalents RP2A07/RP2C07 receive the same optimization automatically.
- Low -> High still records the physical edge, but package logic wakes only when the chip-owned activation period is reached (/6 RP2A03, /4 RP2C02, /8 RP2A07, every rise RP2C07).
- Generic/non-clock traces retain the normal input activation path.
- No signal queue, scheduler, polling, or Settle processing added.

Validation
----------
- Added a regression test that exercises the non-profiled compiled clock path and verifies a falling edge leaves both Famicom clock pins Low without incrementing either rising-edge counter.
- Static source checks performed in packaging environment.
- .NET SDK unavailable here; dotnet test and FPS are not claimed.
