AxetosOS Products / NES v1.3.2

Goal
----
Recover and exceed v1.2.0 throughput while preserving the v1.3.x queue-free physical hardware model.

Runtime changes
---------------
- Coalesce one package output publication into one direct destination reaction per receiving package.
- Reuse thread-local propagation call frames; no central/event/signal/component queue is introduced.
- O(1) duplicate suppression for physical nets touched more than once by one package reaction.
- Compile the topology-validated master oscillator net into a single-driver immediate path.
- Move rising-edge sensitivity and clock division to chip-owned input pins:
  * RP2A03: wake every 6th master-clock rising edge (M2 half-cycle).
  * RP2A07: wake every 8th master-clock rising edge.
  * RP2C02: wake every 4th master-clock rising edge (PPU dot).
  * RP2C07: wake every rising package-clock edge.
- Add prevalidated strong-binary DigitalBus drive/release path.
- Replace retained video/audio Queue<T> capture with reusable ring buffers and bulk Span<T> drains.
- Precompute desktop NES emphasis palettes.
- Avoid redundant RP2C0x NMI drives and extension-bus releases.

Architecture retained
---------------------
- Chips know only their own pins and private state.
- Motherboard traces carry electrical levels and perform only physical trace/net resolution.
- No signal queue, component queue, scheduler, polling Evaluate(), or runtime Settle() processing.
- No CPU/PPU/RAM/ROM semantic shortcuts.

Validation status
-----------------
Static source/overlay checks performed in the packaging environment.
The .NET SDK is unavailable in that environment, so dotnet test and Release FPS are NOT claimed here.
